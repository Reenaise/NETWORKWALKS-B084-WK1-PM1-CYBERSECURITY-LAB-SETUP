# 🔐 Cybersecurity Lab Setup | Week 1

## 📌 Project Overview

This project covers the setup and configuration of a virtual cybersecurity lab using Oracle VirtualBox and Kali Linux as part of the NetworkWalks Cybersecurity Training Program.

The goal was to create a working virtual environment for practicing networking, cybersecurity, and penetration testing.

## 🎯 Project Objectives

- Set up Oracle VirtualBox and Kali Linux.
- Create and configure a private NAT Network.
- Configure static IPv4 addressing and DNS settings.
- Test network and internet connectivity.
- Verify DNS resolution and Nmap installation.
- Create and restore a VirtualBox snapshot.

## 🛠️ Tools and Technologies

- Oracle VirtualBox
- Kali Linux
- Windows 11
- Nmap
- Linux Terminal
- NAT Networking

## ⚙️ Lab Setup and Configuration

### 1. VirtualBox Environment Setup

Prepared Oracle VirtualBox as the virtualization platform for running Kali Linux.

### 2. NAT Network Configuration

Created and configured a private NAT Network to support network communication within the virtual lab.

### 3. Kali Linux Network Adapter Configuration

Configured the Kali Linux virtual machine to use the NAT Network and manually assigned the required IPv4 and DNS settings.

### 4. VirtualBox Snapshot

Created a snapshot to save the virtual machine's configuration and provide a recovery point for future practical exercises.

## ⚠️ Challenges Encountered

One of the main challenges was establishing successful communication between Kali Linux and the configured network gateway.

I investigated the network settings, identified the connectivity issue, and made the necessary corrections until communication was successful.

I also practiced snapshot restoration to understand how to recover a virtual machine to a previously saved configuration.
